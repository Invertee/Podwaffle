# Retired: Podwaffle Ad Detection add-on

Advert analysis is integrated into the main Podwaffle server as of version 6.0.0. This directory is retained for release history; it is no longer an installable add-on or standalone server.

See the [integrated analysis and migration guide](../docs/podcast-analysis.md). Copy any sidecar-only model, Jev, schedule and sensitivity settings before uninstalling the old add-on. Existing results stored by the main server are preserved.
